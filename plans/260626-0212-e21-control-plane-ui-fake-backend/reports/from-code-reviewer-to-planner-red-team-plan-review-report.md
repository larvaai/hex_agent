## Contradicts a user-locked decision (surface to user, do not silently accept)

- **F2** undermines **L3 / R3 / AC S21.16** ("inject reality" + "secret not streamed"): the marquee secret-drop path is unreachable on the current registry and the reused Redactor doesn't drop — the locked safety guarantee is theater until the fake adds an explicit visibility gate.
- **F5** blocks **L1 (full T1 incl. Prompt/Send)**: there is no command_type for Send; honoring L1 requires either declaring one (registry change) or descoping Send — a user call.
- **F8** strains **L2 (static-token authz seam, "drop-in keeps contract")**: the read path is left open, so the seam the user locked as "honest reject + drop-in" is honest only for writes; the read contract the real backend must satisfy is undefined.

## Irreversible / blast-radius note

No data-loss or irreversible path (frontend is an isolated new dir; revert is clean per plan.md:174-177). Highest blast radius is **rework**: F1/F3/F6/F11 all land at the same point — the snapshot/SSE seam is modeled on events the backend doesn't emit and a seq that's never stamped, so the "drop-in = change URL" thesis (the plan's entire justification) fails at wire-up and forces a UI rebuild — exactly the cliff Phase 1 exists to prevent.

- gen_map/tools MAP gap (F14) acceptable IF plan stops claiming MAP coverage for tools.
