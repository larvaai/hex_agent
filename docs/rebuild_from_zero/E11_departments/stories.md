# E11 — Stories (draft)

- **S11.1** — As a user with a research question, the Research Department returns a source-backed summary with citations.
- **S11.2** — As the runtime, the Research Department chains search → read source → extract → cite.
- **S11.3** — As a safety layer, the Safety Department reviews a request/plan and can return `blocked` with reasons.
- **S11.4** — As the supervisor, when Safety returns `blocked`, the run stops before any risky action.
- **S11.5** — As a department, member agents use only their role allowlists (E09) and sandboxed tools (E06).
