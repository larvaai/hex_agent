# E17 — Stories (draft)

- **S17.1** — As a user, I drop a directive into the inbox while a run is active and the agent picks it up at the next step.
- **S17.2** — As the runtime, a user directive takes priority over agent-to-agent suggestions.
- **S17.3** — As a compliance gate, I reject directives that try to disable logging, fabricate tools, or demand hidden chain-of-thought.
- **S17.4** — As the runtime, a goal-changing directive can trigger a replan.
- **S17.5** — As a debugger, every accepted directive is logged as a first-class event.
