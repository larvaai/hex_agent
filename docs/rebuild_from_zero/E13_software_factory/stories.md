# E13 — Stories (draft)

- **S13.1** — As a user with a product prompt, the factory produces an ordered set of spec artifacts.
- **S13.2** — As the factory, each stage writes a named artifact file under the run dir.
- **S13.3** — As the factory, a validator/critic stage checks the product spec before domain/architecture work.
- **S13.4** — As the factory, I produce an implementation spec + a code-handoff packet for the coding runtime.
- **S13.5** — As the supervisor, a `product-build` intent is routed into the factory.
