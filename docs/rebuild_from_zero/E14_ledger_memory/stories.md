# E14 — Stories (draft)

- **S14.1** — As an agent, I append a decision/failure/lesson entry to the ledger.
- **S14.2** — As an agent, I search the ledger by type, tag, or text.
- **S14.3** — As the runtime, ledger entries are append-only and survive process restarts.
- **S14.4** — As an agent, I can retrieve a specific entry by id and see ledger stats.
- **S14.5** — As an agent, lessons can optionally be embedded into the experience RAG for semantic recall.
