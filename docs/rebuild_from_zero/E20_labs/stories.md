# E20 — Stories (draft)

- **S20.1** — As a developer, I run any lab via a single entrypoint (`app lab <name> [cmd]`).
- **S20.2** — As a developer, each lab runs in mock mode offline (no LLM/network).
- **S20.3** — As a user, the repo-understanding lab builds maps + a context pack and answers with evidence only.
- **S20.4** — As a user, the repo-understanding lab flags parse/encoding problems (e.g. BOM) it finds.
- **S20.5** — As a developer, labs reuse shared utilities (discipline/llm/tools) instead of duplicating them.
