# E18 — Stories (draft)

- **S18.1** — As an operator, I open a local dashboard and see the list of runs.
- **S18.2** — As an operator, I open a run and browse its events, filtered by kind/tool.
- **S18.3** — As an operator, I see a run's summary metrics and status.
- **S18.4** — As an operator, I reload to get the latest data for an active run.
- **S18.5** — As a reviewer, the dashboard hosts the plan/diff review gate (E16).
