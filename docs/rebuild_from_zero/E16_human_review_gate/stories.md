# E16 — Stories (draft)

- **S16.1** — As a reviewer, I see an agent's plan and approve, deny, or annotate it before it executes.
- **S16.2** — As a reviewer, I review a diff of uncommitted changes with line-level annotations before commit.
- **S16.3** — As the runtime, a dangerous action (multi-file edit, refactor, architecture change) is gated until approved.
- **S16.4** — As the runtime, a skill/lens update proposal (E15) cannot apply without an approval at this gate.
- **S16.5** — As an agent, I receive the reviewer's annotations as structured feedback and revise accordingly.
