# E15 — Stories (draft)

- **S15.1** — As the harness, I always produce a simple-answer baseline alongside the full-flow answer.
- **S15.2** — As a blind evaluator, I score candidate answers without seeing which agent/flow produced them.
- **S15.3** — As a critical auditor, I flag "multi-agent theater" (wasteful coordination) in a run.
- **S15.4** — As a trace-health check, I detect repeated outputs, JSON fallbacks, and handoff loops.
- **S15.5** — As an evolution decider, I propose changes to agents/flow/skills/lenses but never apply them automatically.
- **S15.6** — As an operator, every proposed change requires explicit human approval (via the review gate).
