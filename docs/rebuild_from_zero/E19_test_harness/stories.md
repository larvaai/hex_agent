# E19 — Stories (draft)

- **S19.1** — As a developer, I run a test group and get pass/fail with logs under `var/test_runs/`.
- **S19.2** — As a developer, deterministic smokes run offline (no LLM/network) and gate every foundation epic.
- **S19.3** — As a developer, `dev_checks --quick` runs a fast subset before commits; `--full` before milestones.
- **S19.4** — As a developer, `capability_suite` aggregates the deterministic capability checks.
- **S19.5** — As a spec author, each epic's core acceptance criteria map to at least one executable test.
